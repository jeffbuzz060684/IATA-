# Assistant IATA — Marchandises Dangereuses

PWA hors ligne installable sur téléphone : colisage, emballage, étiquetage, marquage, DGD, piles &amp; accus (PI 965-970), gaz (PI 200, oxygène), essence (UN 1203), 9 classes.

Déployée automatiquement sur GitHub Pages à chaque push sur `main`.

⚠️ Aide-mémoire de terrain : toujours vérifier l'édition du DGR IATA en vigueur et les variations compagnie (CASS).
